# Emails to send

Eight questions that no amount of scraping can answer. Each is one question,
phrased so it can be answered in a single line — lecturers in August reply to
those and ignore everything else.

**Addresses**: I have not verified a single one and I am not going to invent
them. UniPV uses `nome.cognome@unipv.it`, Statale `nome.cognome@unimi.it`,
Bicocca `nome.cognome@unimib.it`, but exceptions are common. Look each one up
on the departmental staff page before sending.

Order below is by consequence: the first three each block an exam outright.

---
