## Do it in this order

1. The `Exam_Assignments` folder: each sitting is a PDF of the questions with the SMT-LIB encodings that answer it.
2. Take the most recent sittings first, PDF and .smt2 side by side.
3. Install z3 and RUN every encoding. Reading them is not the same as writing them.
4. Then work backwards through the earlier years.
